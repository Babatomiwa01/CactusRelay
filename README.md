# CactusRelay

A sequential innovation exercise from a Russian tomato-rescue story to a surplus coordination venture concept.

## Creative trail
1. 01-story.md — single-paragraph story with Russia, tomato, raccoon, running and a cactus.
2. 02-research-question.md — measurable question derived from the story.
3. 03-problem-statement.md — brief sourced research, narrow segment, evidence limits and pilot gates.
4. 04-solution-design.md — proposed startup, offering, workflow and brand.
5. 05-prototype.md — design specs; prototype.html is the working browser-only demonstrator.
6. index.html — landing page with two real Unsplash photographs and an economics calculator.
7. pitch.html — 13-slide HTML investor deck; 07-business-plan.md contains the business plan and campaign.

All links and assets are relative except Google Fonts, two Unsplash images and research citations. Photos are illustrative, not customer or pilot documentation. Internet access is needed for remote fonts and photographs; local system fonts provide a fallback.

## Open
Open index.html, prototype.html and pitch.html in a browser. Serve this folder over HTTP for predictable localStorage behaviour. The deck supports arrow keys, space, swipe, fullscreen, slide hashes and print-to-PDF. Some slides reveal items progressively. Last slide: Lessons Learned, seven points.
